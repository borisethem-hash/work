# KinTrack 勤怠管理（デモ）

Next.js（App Router / TypeScript）で作成した勤怠管理システムのデモです。

## 起動方法

```bash
npm install
npm run dev        # 開発: http://localhost:3000
# または
npm run build && npm start
```

## デモアカウント（ログイン画面にも表示されます）

| 役割 | メール | パスワード |
| --- | --- | --- |
| 管理者（人事・総務） | admin@demo.jp | admin123 |
| 部署マネージャー（営業部長） | manager@demo.jp | manager123 |
| 一般従業員（営業部） | user@demo.jp | user123 |
| その他の従業員（suzuki@ / ito@ など） | ○○@demo.jp | demo123 |

## 機能

- 打刻：出勤・休憩開始・休憩終了・退勤（状態に応じてボタンを制御）
- 自動集計：労働時間・休憩・残業・深夜（22:00〜5:00）・休日労働
- 遅刻・早退・欠勤・打刻漏れの判定とアラート
- 有給休暇（全日・午前休・午後休）・特別休暇などの申請・承認、残日数管理
- 打刻修正申請 → 承認時に勤怠データへ自動反映
- 管理者・マネージャー：部署別・従業員別のリアルタイム状況、残業ランキング
- 月次集計・日次明細の CSV 出力（Excel 対応の BOM 付き UTF-8）
- 管理者による勤怠の直接修正（修正者・日時を記録、操作履歴）
- 従業員登録・編集、部署管理、就業ルール・休日カレンダー設定
- 権限：管理者＝全社 / マネージャー＝自部署 / 一般＝本人のみ

## データについて

デモ用のため、データはブラウザの localStorage に保存されます（サーバー・DB不要）。
過去3か月分のサンプル勤怠が自動生成され、日付が変わると当日基準で再生成されます。
設定 → デモデータ から手動で初期化できます。
